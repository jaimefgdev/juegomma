# Octágono Pixel

Juego de MMA en pixel art para el navegador: 16 luchadores de distintos pesos (leyendas inspiradas en peleadores reales, con nombres inventados), montada, sumisiones, TKO, KO y decisión de los jueces. Contra la CPU o a dos jugadores en el mismo teclado.

Juega en https://jaimefgdev.com/juegomma/
